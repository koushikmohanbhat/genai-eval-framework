# Evals

Generated by `genai-evals init`. Full documentation: https://github.com/koushikmohanbhat/genai-eval-framework/tree/main/docs

| File | What it is | Commit it? |
|---|---|---|
| `suite.yaml` | dataset, targets (the system under test), graders and release gates | yes |
| `providers.yaml` | offline mock profiles, so the suite runs with no keys | yes |
| `providers.live.yaml` | real model profiles; every environment-specific value is a `${VAR}` | yes |
| `sources.yaml` | production telemetry for online evals (CloudWatch / AgentCore, Cloud Trace / BigQuery) | yes |
| `online_checks.yaml` | reference-free graders and gates for online evals | yes |
| `data/cases.jsonl` | the golden set: one case per line | yes (tokenised, no raw personal data) |
| `prompts/` + `prompts.lock` | versioned prompts and which version each stage uses | yes |
| `.env.example` | every setting the YAML reads, with no values | yes |
| `.env` | your values (regions, projects, model ids, keys) | **no** (gitignored) |
| `ci/github-actions-evals.yml` | GitHub Actions workflow to copy into `.github/workflows/` | yes |

## 1. Run offline

```bash
genai-evals run suite.yaml
```

This uses the mock profiles in `providers.yaml`. It should pass all gates and write an HTML report under
`.genai-evals/runs/`.

## 2. Go live

```bash
cp .env.example .env        # fill in only what you use
genai-evals validate suite.yaml --providers providers.live.yaml
genai-evals check-config providers.live.yaml
genai-evals run suite.yaml  # with GENAI_EVALS_PROVIDERS=providers.live.yaml and EVAL_TARGET_PROFILE set in .env
```

In `providers.live.yaml`, delete the profiles you don't use. A `${VAR}` without a default must be set, and the
error message names the missing variable. Cloud setup (credentials, IAM roles, which telemetry to switch on):
see `docs/setup-aws.md`, `docs/setup-gcp.md` and `docs/setup-openai-anthropic.md` in the framework repo.

## 3. Make it yours

1. Replace `data/cases.jsonl` with 50–300 real cases from your use case: inputs, reference answers, tags for
   slicing, and `critical: true` on the ones that must never fail.
2. Replace `prompts/assistant/1.0.0` with your prompt (or point the target at your deployed agent: AgentCore
   Runtime, Bedrock Agents, Vertex Agent Engine, an HTTP endpoint).
3. Choose graders and set gate thresholds with the business owner.
4. Calibrate the judges against 30–50 human labels: `genai-evals calibrate`.
5. Save a baseline and add the CI workflow.
